# Thelu Clothes Shop

Premium fashion e-commerce and private stock/order management dashboard.

## Stack
- React + TypeScript + Vite
- Motion for React
- React Router
- Cloudflare-ready architecture

## Project areas
- Public storefront: premium animated home, shop, filters, product detail, cart
- Private admin: login, dashboard, products, inventory, orders

> Brand assets (logo, real product photography, copy and social links) can be dropped in without changing the application structure.
